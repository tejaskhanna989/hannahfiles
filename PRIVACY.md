# HannahFiles Privacy Policy

HannahFiles is a joke file manager. It collects nothing, tracks nothing,
and sends nothing anywhere — except for one thing:

**Update checks.** On launch (at most once every 24 hours), the Linux build
may request `https://api.github.com/repos/tejaskhanna989/hannahfiles/releases/latest`
to see if a newer version exists. Like any web request, this exposes your IP
address to GitHub. No other data is sent, nothing is stored by us, and you can
disable update checks in the app's settings.

The Windows build does not check for updates on its own.

The wallpaper images bundled with HannahFiles are third-party Creative Commons
photos; see `wallpapers/ATTRIBUTION.md` for credits.

Questions: open an issue at <https://github.com/tejaskhanna989/hannahfiles/issues>.
