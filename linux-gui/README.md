# HannahFiles GUI for Linux

A **joke** graphical file manager for Linux (GPLv3): tabs, dual-pane,
search, preview, favorites, tags, dark pop-star theme — with Miley in the
preview pane when nothing is selected.

```bash
cd linux-gui
npm install
npm start        # run
npm run dist:linux  # build AppImage + .deb into dist/
```

Installers are built on CI (`HannahFiles CI — Linux GUI`) and attached to
tagged releases.
